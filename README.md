# Итоговый проект. Агентство недвижимости

Сервис для предсказания стоимости домов на основе истории предложений (объявлений о продаже).

## Задача

Крупное агентство недвижимости тратит много времени на ручной анализ объявлений.
Нужен инструмент, который по характеристикам объекта (площадь, число спален и ванных,
этажность, год постройки, тип жилья, регион) быстро оценивает его стоимость.

Формально это задача регрессии: по признакам объекта предсказать цену.

## Данные

Датасет — история предложений о продаже домов (предоставлен в рамках курса):
https://drive.google.com/file/d/11-ZNNIdcQ7TbT8Y0nsQ3Q0eiYQP__NIW/view

Файл `data.csv` (~377 тыс. строк) не включён в репозиторий из-за размера — его нужно
положить в корень проекта перед запуском ноутбука.

## Что сделано

- **Предобработка:** парсинг цены (`$418,000` → число), извлечение чисел из `sqft`, `beds`,
  `baths`, год постройки из JSON-поля `homeFacts`, нормализация типа жилья, отбрасывание
  некорректных значений. После очистки ≈235 тыс. объектов.
- **EDA:** распределения цены и логарифма цены, цена по типам жилья и штатам,
  связь площади и цены, корреляционная матрица.
- **Статистика:** Спирмен (площадь–цена, ρ≈0.55), Манн–Уитни (single_family vs condo),
  ANOVA по типам жилья — все различия значимы.
- **Модели:** baseline (медиана), линейная регрессия, градиентный бустинг
  (HistGradientBoosting с категориальными признаками, цель — log(1 + price)).
- **Сервис:** сохранение модели (`joblib`), функция `predict_price`, пакетное предсказание.

## Результаты

| Модель | MAE, $ | RMSE, $ | R² | MedAPE, % |
|---|---|---|---|---|
| Baseline (медиана) | 418 315 | 1 159 152 | −0.06 | 48.5 |
| Линейная регрессия | 407 269 | 901 851 | 0.36 | 59.5 |
| **Градиентный бустинг** | **228 212** | **663 916** | **0.65** | **24.7** |

Кросс-валидация (3 фолда) для бустинга: R² ≈ 0.735.

Наибольший вклад в прогноз дают площадь (0.53), регион/штат (0.39), число ванных (0.19)
и тип жилья (0.11).
